# Sistema de diseño

Entregado por Claude Design el 2026-11-26 a partir del encargo del fundador. Es la fuente de verdad del diseño del visor: las historias lo integran en `site/`. Este directorio no se publica tal cual.

- `site/GUIA-DE-MARCA.md`: nombre, logo, color, capas del mapa, lenguaje y avisos obligatorios.
- `site/css/tokens.css` y `site/css/tokens.json`: tokens de color, tipografía, espaciado y radios, en claro y oscuro.
- `site/css/componentes.css` y `site/componentes.html`: componentes del visor (cabecera, panel de capas, leyenda, atribución, avisos, ficha de evidencia y estados).
- `site/js/estilos-capas.js`: estilos de las capas para Leaflet (color, grosor, patrón y halo).
- `site/img/`, `site/favicon.svg`, iconos PNG, `site/og-image.png` y `site/site.webmanifest`: logo, favicons, iconos e imagen para redes.
- `site/fonts/LEEME.md`: cómo generar los WOFF2 de Atkinson Hyperlegible (SIL OFL 1.1). Los ficheros de fuente no vienen incluidos.
